# ترجمان | TARJUMAN BOT

بوت تيليجرام لترجمة النصوص والنصوص الموجودة داخل الصور، مع دعم الرد على الرسائل في المحادثات والمجموعات.

## المزايا
- اكتب **ترجم** ردًا على رسالة لترجمتها تلقائيًا.
- العربية تُترجم افتراضيًا إلى الإنجليزية، والنص غير العربي إلى العربية.
- تحديد اللغة: **ترجم للإنجليزية** أو **ترجم للفرنسية** أو رمز اللغة مثل **ترجم es**.
- الرد بكلمة «ترجم» على صورة لاستخراج النص ثم ترجمته.
- تقسيم النصوص الطويلة إلى أجزاء مناسبة لخدمات الترجمة ورسائل تيليجرام.
- يعمل على Cloudflare Workers ولا يحتاج خادمًا دائمًا.

## أمثلة
| ما ترسله | النتيجة |
|---|---|
| رد على رسالة: ترجم | ترجمة تلقائية عربي ↔ إنجليزي |
| رد على رسالة: ترجم للفرنسية | ترجمة إلى الفرنسية |
| رد على صورة: ترجم | استخراج النص ثم ترجمته |
| ترجم Hello, how are you? | ترجمة النص المكتوب بعد الأمر |

## الخدمات والحدود
- Cloudflare Workers: الخطة المجانية تتضمن حصة يومية للطلبات وليست بلا حدود.
- MyMemory: الاستخدام المجاني المجهول محدود حاليًا بنحو 5,000 حرف يوميًا، وقد يرتفع إلى 50,000 مع بريد صالح.
- OCR.space: يتطلب مفتاح API مجانيًا، والخطة المجانية المعلنة محدودة بعدد الطلبات يوميًا.
- حدود وشروط وتوافر الخدمات الخارجية قابلة للتغيير. لا توجد ترجمة مجانية غير محدودة مضمونة.

## النشر
راجع docs/DEPLOYMENT.md لإعداد Cloudflare وإضافة الأسرار وربط Webhook تيليجرام.

## الأمان
لا تضع Bot Token أو مفاتيح الخدمات داخل ملفات المشروع. استخدم Secrets في Cloudflare فقط.
