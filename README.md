# ترجمان | TARJUMAN BOT

بوت تيليجرام لترجمة النصوص والنصوص الموجودة داخل الصور، مع دعم الرد على الرسائل في المحادثات والمجموعات.

## المزايا
- حدّد لغة الهدف صراحةً بكتابة **ترجم للإنجليزية** أو **ترجم للفرنسية** أو اسم أي لغة مدعومة.
- أرسل الأمر ردًا على رسالة أو صورة، أو اكتب النص بعد الأمر مباشرة.
- يدعم البوت صيغًا قريبة مثل **ترج** و**ترجمان** و**ترجملي** مع تحديد اللغة بالطريقة نفسها.
- اختيار لغة افتراضية من أزرار البوت، مع حفظ تفضيل كل مستخدم عبر Cloudflare KV.
- تحديد اللغة لطلب واحد: **ترجم للإنجليزية** أو **ترجم للفرنسية** أو رمز اللغة مثل **ترجم es**.
- رسالة ترحيب شخصية، شرح الاستخدام، زر قناة التحديثات، وزر إضافة البوت للمجموعات عند ضبط BOT_USERNAME.
- التحقق من بعض أخطاء اللغة الواضحة ورفض النتائج التي تعيد النص العربي كما هو عند طلب لغة أخرى.
- محرك Meta M2M100-1.2B عبر Cloudflare Workers AI هو المحرك الأساسي للنصوص التي يمكن تحديد لغتها، مع Gemini وGoogle وLibreTranslate وMyMemory كمحركات احتياطية.
- الرد بكلمة «ترجم» على صورة لاستخراج النص ثم ترجمته.
- توسيع معالجة اختصارات المحادثات الإنجليزية والتعبيرات العامية المصرية قبل الترجمة.
- ذاكرة عبارات عملية للعربية والإنجليزية والفرنسية، مع تطبيع عامية عربي محافظ.
- دعم صيغ تحديد اللغة بلغات متعددة، مثل In French وEn français وAuf Deutsch.
- إعادة محاولة بعض أعطال خدمات الترجمة المؤقتة، والتحقق من عدم فقدان النفي والسبب والإشارات الزمنية الواضحة.
- فحوص آلية لسلامة ملفات القواميس وتجميع Worker عبر GitHub Actions.
- تقسيم النصوص الطويلة إلى أجزاء مناسبة لخدمات الترجمة ورسائل تيليجرام.
- يعمل على Cloudflare Workers ولا يحتاج خادمًا دائمًا.

## أمثلة
| ما ترسله | النتيجة |
|---|---|
| رد على رسالة: ترجم للإنجليزية | ترجمة الرسالة إلى الإنجليزية |
| رد على رسالة: ترجم للفرنسية | ترجمة الرسالة إلى الفرنسية |
| رد على صورة: ترجم للعربية | استخراج النص ثم ترجمته إلى العربية |
| ترجم للألمانية Good morning | ترجمة النص المكتوب بعد الأمر إلى الألمانية |

## الخدمات والحدود
- Gemini: محرك احتياطي عند ضبط GEMINI_API_KEY؛ يظل M2M100 هو المحرك الأساسي للنصوص التي يتعرف البوت على لغتها.
- Cloudflare Workers AI (Meta M2M100-1.2B): نموذج ترجمة متعدد اللغات مستضاف لدى Cloudflare؛ يتطلب تفعيل ربط AI وقد تُطبق عليه رسوم الاستخدام وفق حساب Cloudflare.
- MyMemory: الاستخدام المجاني المجهول محدود حاليًا بنحو 5,000 حرف يوميًا، وقد يرتفع إلى 50,000 مع بريد صالح.
- OCR.space: يتطلب مفتاح API مجانيًا، والخطة المجانية المعلنة محدودة بعدد الطلبات يوميًا.
- حدود وشروط وتوافر الخدمات الخارجية قابلة للتغيير. لا توجد ترجمة مجانية غير محدودة مضمونة.

## فحص ملفات اللغة

شغّل `npm run test:data` للتحقق من سلامة ملفات العبارات والاختصارات والعامية. يفحص GitHub Actions هذه الملفات ويجري بناءً تجريبيًا للـ Worker عند كل تحديث.

## النشر
راجع docs/DEPLOYMENT.md لإعداد Cloudflare وإضافة الأسرار وربط Webhook تيليجرام.

## خصوصية الترجمة
عند استخدام Gemini عبر المستوى المجاني، قد تستخدم Google المحتوى المرسل لتحسين منتجاتها وفق شروطها. لا ترسل عبر البوت كلمات مرور أو بيانات مالية أو معلومات شديدة الحساسية. إذا لم يُضف GEMINI_API_KEY، يستمر البوت باستخدام محركاته الاحتياطية الحالية.

## الأمان
لا تضع Bot Token أو مفاتيح الخدمات داخل ملفات المشروع. استخدم Secrets في Cloudflare فقط.
